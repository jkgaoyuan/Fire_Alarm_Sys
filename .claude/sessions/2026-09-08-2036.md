## 关键决策

- **DEC-001**: Refresh Token 完全由后端 httpOnly Cookie 承载，前端不存储、不读取
  - **原因**: 防止 XSS 窃取 Refresh Token
  - **影响范围**: `backend/app/api/v1/auth.py` + `frontend/src/utils/request.js`
- **DEC-002**: Token 刷新采用"主动检查 + 401 兜底"双保险策略
  - **原因**: 避免纯被动刷新导致的首次请求 401 闪错
  - **影响范围**: `frontend/src/utils/request.js`
- **DEC-003**: v-permission 默认行为为 CSS 隐藏（display: none），可选 remove/disabled 修饰符
  - **原因**: 避免布局跳动
  - **影响范围**: `frontend/src/directives/permission.js`
