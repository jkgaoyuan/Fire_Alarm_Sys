### 4. 核心服务 (3.5-B2/B3) ✓

**文件**: `backend/app/services/emergency_service.py`

#### 核心功能
```python
✅ create_emergency_event(alarm_id, creator_id)
   └─ 真实火警确认时自动生成事件+timeline(alarm+confirm)

✅ scan_pending_alarms_for_escalation()
   └─ 每 60 秒扫描 pending_since≥5min 的报警→生成主管通知

✅ add_timeline_node(event_id, node_type, operator_id, ...)
   └─ 添加入置节点 (evacuate/control/check_in/photo/complete)

✅ resolve_emergency_event(event_id, summary, resolver_id)
   └─ 标记完成+添加 complete 节点

✅ close_emergency_event(event_id, closer_id)
   └─ 强制关闭 (主管权限)

✅ get_user_notifications(user_id, page, page_size, module)
   └─ 分页获取通知列表

✅ mark_notifications_as_read(user_id, notification_ids)
   └─ 批量标记已读

✅ get_unread_count(user_id)
   └─ 未读数统计
```
