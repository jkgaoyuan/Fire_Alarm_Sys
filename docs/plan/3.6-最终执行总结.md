### 关键功能路径验证

#### 1. 巡检计划管理（FR-032）
```
✅ 创建计划 → 选择周期(daily/weekly/monthly/quarterly/yearly)
    ↓ 设置区域 + 设备类型 + 责任人
✅ 启用/停用切换
✅ 手动触发立即生成任务
✅ Response: 200 OK
```

#### 2. 每日任务生成（FR-033）
```
✅ lifespan 启动 → asyncio 后台任务每小时执行
    ↓ 扫描 is_enabled=True 的计划
    ↓ 按 cycle_type 判断是否需要生成
    ↓ INSERT ... ON CONFLICT DO NOTHING（幂等）
✅ 任务状态: pending → 待执行
```

#### 3. PC 端手动巡检（FR-034）
```
✅ 维保人员选择当日任务 → 逐个设备填报
    ↓ result='normal' → 记录正常
    ↓ result='abnormal' → 填写异常描述
    ↓ 全部设备填报完成 → task.status='completed'
✅ 异常自动创建维修工单（幂等性保证）
```

#### 4. 漏检统计与预警（FR-035）
```
✅ 每小时扫描昨日 status 仍为 pending/doing 的任务
    ↓ 标记为 missed
    ↓ 按 responsible_user_id 统计近 30 天漏检次数
    ↓ >3 次 → 发送系统内通知给主管
✅ Response: 漏检计数 + 通知发送
```

#### 5. 巡检异常转维修工单（FR-038 关联）
```
✅ 巡检填报 result='abnormal'
    ↓ 检查 inspection_record_id 唯一约束
    ↓ 如不存在 → 自动创建 repair_order
    ↓ 幂等性：同一巡检记录不会重复创建工单
✅ 工单 status='pending'，等待派单
```
