## 🎯 核心功能特性

### 1. 工单状态机

```
pending → assigned → repairing → pending_accept → completed
                                ↓
                            returned → repairing (循环)
```

**6 种状态**:
- `pending`: 待处理
- `assigned`: 已派单
- `repairing`: 维修中
- `pending_accept`: 待验收
- `completed`: 已完成（验收通过）
- `returned`: 已退回（验收不通过）

### 2. 权限矩阵

| 操作 | 消防值班员 | 维保人员 | 消防主管 |
|------|:----------:|:--------:|:--------:|
| 查看工单 | ✅ | ✅ | ✅ |
| 创建工单 | ✅ | ✅ | ✅ |
| 派单 | ❌ | ❌ | ✅ |
| 完成维修 | ❌ | ✅ | ❌ |
| 验收通过 | ❌ | ❌ | ✅ |
| 验收退回 | ❌ | ❌ | ✅ |

### 3. 自动化逻辑

**巡检异常自动转工单流程**:
1. 维保人员提交巡检记录（`result='abnormal'`）
2. 系统自动检查是否已存在关联工单（幂等性）
3. 如不存在，自动创建维修工单
4. 工单状态为 `pending`，等待派单

### 4. 数据完整性保证

- `inspection_record_id` 唯一约束 → 防止重复创建
- 验收通过后自动恢复设备状态为 `normal`
- 事务控制保证数据一致性
