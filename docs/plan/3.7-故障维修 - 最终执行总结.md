#### 4. 统计接口 (T11-T14)
```python
✅ GET /api/v1/repair-statistics/overview
    ↓ call crud.get_avg_repair_duration()
    ↓ call crud.get_status_distribution()
    ↓ calculate total and average
    ↓ return {"avg_repair_hours": X, "total_orders": Y, "status_distribution": [...]}

✅ GET /api/v1/repair-statistics/by-repairer
    ↓ call crud.get_workload_by_repairer()
    ↓ group by repairer_id
    ↓ count(total), sum(completed) per person
    ↓ return WorkloadResponse(items=[{name, total, completed}, ...])

✅ GET /api/v1/repair-statistics/fault-types
    ↓ call crud.get_fault_type_distribution()
    ↓ join devices.device_type_id -> device_types.type_name
    ↓ group by type_name, count(id)
    ↓ return FaultDistributionResponse(items=[{type_name, count}, ...])

✅ GET /api/v1/repair-statistics/top10-devices
    ↓ call crud.get_top10_fault_devices()
    ↓ join repair_orders.device_id -> devices
    ↓ group by device_code, device_name, type_name
    ↓ order by count desc, limit 10
    ↓ return Top10FaultDevicesResponse(items=[{device_code, fault_count}, ...])
```
