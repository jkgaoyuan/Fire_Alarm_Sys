# 开发计划更新说明 - 3.8 消防演练

## 根据用户决策进行的修改

### ✅ OQ-5: 权限矩阵调整（方案一）
**决策：消防主管或值班员均可执行演练**

修改内容：
- 维保人员增加备注"(技术支援)"，明确其可执行但主要是技术支持角色
- 保持消防值班员和消防主管均拥有 `drill:execute` 权限

### ✅ OQ-6: 删除冗余字段 `is_drill_data`
**决策：直接删除字段**

修改内容：
- 从 `drill_events` 表结构中移除 `is_drill_data BOOLEAN DEFAULT TRUE` 字段
- 从 Python 模型 `DrillEvent` 中移除 `is_drill_data: Mapped[bool] = mapped_column(default=True)`
- 理由：该字段冗余，表名已能唯一标识演练数据

### ✅ OQ-4: 合并 `summary` 字段至评估表
**决策：将 summary 迁移至 drill_evaluations.evaluation_summary**

修改内容：
1. **保留** `drill_events.summary` (TEXT) - 用于现场记录类信息
2. **新增** `drill_evaluations.evaluation_summary` (TEXT) - 用于总体评估摘要

说明：
- 原设计中的 `drill_events.summary` 不做删除，而是作为"演练总结"保留
- 在 `drill_evaluations` 表新增 `evaluation_summary` 字段用于评估报告汇总
- 这样两者可以各司其职，避免功能重叠
