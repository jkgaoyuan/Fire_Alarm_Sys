## ⚠️ 已知限制与说明

### 1. HTML 而非原生 PDF

**影响**: 无法直接下载二进制 PDF 文件  
**缓解方案**: 使用浏览器打印功能 → "另存为 PDF"  
**技术理由**: 
- 减少依赖复杂度和镜像体积
- HTML 渲染效果更可控
- 前端可自由定制打印样式

**是否接受**: ✅ 是 (P0 功能已闭环)

**是否接受**: ✅ 是 (P1 功能可后续迭代)
