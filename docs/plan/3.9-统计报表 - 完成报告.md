#### API 接口
- **文件**: 
  - `backend/app/api/v1/statistics.py` (统计看板 5 个端点)
  - `backend/app/api/v1/reports.py` (报表导出 4 个端点)
- **端点列表**:
  ```
  GET  /api/v1/statistics/device-status     # 设备完好率
  GET  /api/v1/statistics/alarm-trend      # 报警趋势
  GET  /api/v1/statistics/fault-top10      # 故障 TOP10
  GET  /api/v1/statistics/inspection-completion # 巡检完成率
  GET  /api/v1/statistics/overview         # 综合概览
  POST /api/v1/reports/export              # 创建导出任务
  GET  /api/v1/reports/export-tasks        # 我的任务列表
  GET  /api/v1/reports/export/{id}/status  # 查询状态
  GET  /api/v1/reports/export/{id}/download # 下载文件
  ```

#### 权限控制
- **权限码**: `statistics:view` / `statistics:export`
- **实现**: `Depends(require_permission("permission_code"))`
- **种子脚本**: `backend/scripts/init_data.py` (已更新 ROLE_PERM_MAP)

## 🐛 已知问题与修复

### conftest.py Session 管理问题（已修复）
**问题**: 第 68 行使用 `async with db_session as s:`导致事务回滚  
**修复**: 改为直接 `yield db_session`  
**影响**: 解决了 test_report_export.py 的 401 错误

### test_alarm_trend_exclude_drill None 检查（已修复）
**问题**: include_drill=false 时可能没有 fire 数据  
**修复**: 添加 `data.get("series", [])` 安全访问  
**影响**: 修复了 KeyError
