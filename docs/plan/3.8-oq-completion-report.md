### ✅ **工作 2: Drill 模型文件创建**

**文件路径：** `backend/app/models/drill.py`

**实现内容：**

#### 1. DrillEvent 模型
```python
class DrillEvent(Base):
    """
    演练事件表
    记录消防演练计划、执行过程和现场记录
    
    设计说明：
    - summary: 用于现场执行记录类信息（如："演练按计划完成，参与人数 50 人，用时 30 分钟"）
    - is_drill_data 字段已移除（冗余标识）- OQ-6 决策
    """
```

**核心字段：**
- `drill_name`: 演练名称
- `drill_type`: 类型 (evacuation/firefighting/comprehensive)
- `status`: 状态机 (planned/ongoing/completed/cancelled)
- `summary`: 现场记录总结
- `photos/videos`: 多媒体附件
- `participants`: 参与人员 JSONB 数组

#### 2. DrillEvaluation 模型
```python
class DrillEvaluation(Base):
    """
    演练评估表
    记录演练的评估打分和专业总结
    
    设计说明：
    - evaluation_summary: 总体评估摘要（OQ-4 决策新增）
    - 与 DrillEvent.summary 各有侧重：前者专业总结，后者现场记录
    """
```

**核心字段：**
- `drill_id`: 唯一关联演练事件
- `items`: 评估项打分数组 (JSONB)
- `total_score`: 总分
- `problems`: 存在问题
- `improvements`: 改进措施
- `evaluation_summary`: 总体评估摘要（新增）

#### 3. 双向关联关系
```python
# DrillEvent ↔ DrillEvaluation 1:1
evaluation = relationship(
    "DrillEvaluation",
    back_populates="drill_event",
    uselist=False,
    cascade="all, delete-orphan"
)
```

**级联策略：**
- 删除演练时自动删除对应评估
- 确保数据完整性
