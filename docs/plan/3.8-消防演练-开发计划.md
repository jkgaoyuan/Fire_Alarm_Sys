## 三、总体设计

### 3.1 数据流

```
演练计划（drill_events.status='planned'）
        │
        ├── 演练开始 ──▶ status='ongoing'
        │                  │
        │                  ├── 模拟器/手动触发报警 ──▶ alarms.is_drill=true
        │                  │                              │
        │                  ├── 联动预案执行（is_simulation=true）
        │                  │                              │
        │                  ├── 时间节点记录 ──▶ drill_event 时间轴
        │                  │
        │                  └── 现场照片/视频上传
        │
        ├── 演练结束 ──▶ status='completed'
        │
        ├── 评估打分 ──▶ drill_evaluations
        │
        └── 生成报告 ──▶ PDF 导出 / 归档
```

### 3.2 演练数据隔离规则

1. 所有统计 API（3.9）默认过滤 `is_drill=false`。
2. 报警中心默认不展示 drill 报警，提供"显示演练数据"开关（主管可见）。
3. 演练期间联动动作使用 `is_simulation=true`，不生成真实设备指令。
4. 演练不生成真实 `emergency_events`，避免污染应急事件列表。

### 3.3 演练与模拟器集成

- 演练开始后，模拟器上报接口 `POST /monitor/report` 支持 `is_drill=true`。
- 手动触发报警按钮在演练详情页，调用报警创建内部接口并强制 `is_drill=true`。
- 联动引擎匹配到 drill 报警时，自动以 `is_simulation=true` 执行。

### 3.4 评估项模板

```json
[
  {"item": "response_time", "label": "响应时间", "score": 85, "max_score": 100, "comment": ""},
  {"item": "evacuation_efficiency", "label": "疏散效率", "score": 90, "max_score": 100, "comment": ""},
  {"item": "linkage_effect", "label": "设备联动", "score": 80, "max_score": 100, "comment": ""},
  {"item": "personnel_cooperation", "label": "人员配合", "score": 88, "max_score": 100, "comment": ""}
]
```

### 4.3 模型骨架

```python
# app/models/drill.py
class DrillEvent(Base):
    __tablename__ = "drill_events"
    drill_name: Mapped[str] = mapped_column(String(100))
    drill_type: Mapped[str] = mapped_column(String(20))
    planned_at: Mapped[Optional[datetime]] = mapped_column(DateTime(timezone=True), nullable=True)
    actual_start_at: Mapped[Optional[datetime]] = mapped_column(DateTime(timezone=True), nullable=True)
    actual_end_at: Mapped[Optional[datetime]] = mapped_column(DateTime(timezone=True), nullable=True)
    location: Mapped[Optional[str]] = mapped_column(String(255), nullable=True)
    participants: Mapped[list[dict]] = mapped_column(JSONB, default=list)
    status: Mapped[str] = mapped_column(String(20), default="planned")
    is_drill_data: Mapped[bool] = mapped_column(default=True)
    summary: Mapped[Optional[str]] = mapped_column(Text, nullable=True)
    photos: Mapped[list[dict]] = mapped_column(JSONB, default=list)
    videos: Mapped[list[dict]] = mapped_column(JSONB, default=list)

class DrillEvaluation(Base):
    __tablename__ = "drill_evaluations"
    drill_id: Mapped[int] = mapped_column(ForeignKey("drill_events.id"), unique=True, index=True)
    evaluator_id: Mapped[int] = mapped_column(ForeignKey("users.id"))
    evaluated_at: Mapped[datetime] = mapped_column(DateTime(timezone=True), default=func.now())
    items: Mapped[list[dict]] = mapped_column(JSONB)
    total_score: Mapped[Optional[int]] = mapped_column(Integer, nullable=True)
    problems: Mapped[Optional[str]] = mapped_column(Text, nullable=True)
    improvements: Mapped[Optional[str]] = mapped_column(Text, nullable=True)
```

### 后端技术要点

1. **演练上下文**：`drill_service.get_active_drill()` 返回当前进行中的演练；报警创建时检测是否有 active drill，自动标记 `is_drill=true`。
2. **不生成真实应急事件**：`is_drill=true` 的报警确认真实火警时，不创建 `emergency_events`。
3. **数据权限**：演练列表按 `created_by`/`org_id` 过滤；首版按创建人可见，主管可见全部。
4. **评估唯一性**：`drill_evaluations.drill_id` 唯一约束；重复提交则更新。

## 十一、风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| drill 报警污染真实统计 | 数据错误 | 所有统计 API 默认过滤 `is_drill=false`；报警中心默认隐藏 |
| 演练期间真实报警也被标记 drill | 误隔离 | 仅通过演练执行面板触发的报警标记 drill；真实模拟器上报仍按实际标记 |
| 多演练并发 | 上下文混乱 | 同一时间不允许多个 `ongoing`；start 时校验 |
| 视频上传过大 | 存储/带宽压力 | 限制 100MB；大视频建议外部存储 |
