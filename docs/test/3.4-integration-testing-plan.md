## 🔧 联调方案选择

### 方案 A: Docker Compose 一键启动 (推荐)
**适用场景**: 开发环境快速测试  
**优点**: 自动启动所有服务  
**缺点**: 需要完整 Docker 环境

```bash
# 启动所有服务
docker-compose up -d

# 查看日志
docker-compose logs -f backend frontend

# 访问 Swagger
http://localhost:8000/docs

# 访问前端 UI
http://localhost:5173
```

### 方案 B: 本地服务 + 远程 DB (当前推荐)
**适用场景**: 已有本地 Python/Vue 环境  
**优点**: 调试更方便，代码热更新  
**缺点**: 需手动启动各服务

```bash
# 1. 启动后端 (Terminal 1)
cd backend
uvicorn app.main:app --reload --host 127.0.0.1 --port 8000

# 2. 启动前端 (Terminal 2)
cd frontend
npm run dev

# 3. 手动测试 API
curl http://localhost:8000/api/v1/linkage-plans
```

### 方案 C: 纯后端 API 联调 (最快验证)
**适用场景**: 仅需验证后端接口  
**优点**: 无需启动前端，直接使用 Swagger  
**缺点**: 不验证前端 UI 集成

```bash
cd backend
python -m pytest tests/test_linkage_quick.py -v
```

## 🎯 联调测试用例

### 用例 1: 创建预案 (Create)

**请求**:
```javascript
// POST /api/v1/linkage-plans
{
  "plan_name": "东侧火警联动预案",
  "org_id": 1,
  "fire_type": "fire",
  "trigger_alarm_type": "fire",
  "actions": [
    {
      "action_type": "start_exhaust",
      "params": {"zone": "东侧"}
    },
    {
      "action_type": "close_door",
      "params": {"door_id": 15}
    }
  ],
  "is_enabled": true
}
```

**预期响应**:
```json
{
  "code": 200,
  "message": "创建成功",
  "data": {
    "id": 1,
    "plan_name": "东侧火警联动预案",
    "is_enabled": true
  }
}
```

**前端测试**:
1. 访问 `http://localhost:5173` → 联动预案管理
2. 点击"新建预案"按钮
3. 填写表单并提交
4. 验证列表显示新创建的预案

## 🔍 问题排查清单

如果联调失败，检查以下几点:

### 1. 路由注册问题
```python
# 确认路由已注册
cat backend/app/api/v1/__init__.py
# Should include: router.include_router(linkage_plans.router)
```

### 2. 权限配置问题
```python
# 检查 permission_code 是否定义
grep "linkage:" backend/app/core/security.py
# Expected: 'linkage:create', 'linkage:update', ...
```

### 3. 数据库迁移问题
```bash
# 检查表是否存在
psql -U postgres -d fire_alarm -c "\dt *linkage*"
```

### 4. CORS 问题 (前端)
```javascript
// frontend/src/utils/request.js
axios.create({
  baseURL: 'http://localhost:8000/api',
  withCredentials: true,
})
```
