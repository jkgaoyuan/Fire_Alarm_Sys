  - `on_alarm_created()` - 新报警触发自动联动

## 💡 使用说明

### 创建联动预案示例

**请求**:
```json
POST /api/v1/linkage-plans
{
  "plan_name": "1F 大厅火警联动",
  "org_id": 1,
  "fire_type": "fire",
  "trigger_device_type_id": null,
  "trigger_alarm_type": "fire",
  "actions": [
    {
      "action_type": "start_exhaust",
      "target_device_type_id": 6,
      "params": { "zone": "东侧" }
    },
    {
      "action_type": "close_door",
      "params": { "door_id": "D-001" }
    }
  ],
  "is_enabled": true,
  "is_simulation_allowed": true
}
```

**响应**:
```json
{
  "id": 1,
  "plan_name": "1F 大厅火警联动",
  "org_id": 1,
  "fire_type": "fire",
  "trigger_alarm_type": "fire",
  "actions": [...],
  "is_enabled": true,
  ...
}
```

### 手动执行预案示例

**请求**:
```json
POST /api/v1/linkage-plans/execute
{
  "alarm_id": 88,
  "is_simulation": false,
  "remark": "值班员手动触发"
}
```

### 联动日志导出示例

**请求**:
```
GET /api/v1/alarm-linkage-logs/export?alarm_id=88&status=success
```

**响应**: CSV 格式下载文件
