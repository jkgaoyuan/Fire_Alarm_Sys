### ❌ 失败的测试 (8 条)

所有失败均由同一根本原因导致：

#### 🔧 错误类型
```
sqlalchemy.exc.MissingGreenlet: greenlet_spawn has not been called; 
can't call await_only() here. Was IO attempted in an unexpected place?
```

#### 📍 影响范围
- `test_list_empty_plans` 
- `test_create_valid_plan`
- `test_invalid_cycle_type`
- `test_empty_plan_name`
- 以及 E2E 测试文件中的所有用例

#### 🔍 根本原因分析

**问题根源**: `conftest.py` 中的 `db_session` fixture 存在异步会话生命周期管理缺陷。

**详细路径**:
1. `db_session` fixture → 创建 AsyncSession
2. `client` fixture → 使用 `db_session` 作为 dependency_overrides  
3. `test_user` fixture → 尝试对 `db_session` 执行 `add()/commit()/flush()`
4. ⚠️ 此时 session 不在事件循环上下文中 → MissingGreenlet 错误

**技术细节**:
```python
@pytest_asyncio.fixture
async def db_session(db_engine):
    session = TestingSessionLocal()  # ← 创建的是 AsyncSession
    try:
        yield session  # ← 但在 yield 后没有正确的 await 上下文
    finally:
        session.close()  # ← RuntimeWarning: coroutine 'AsyncSession.close' never awaited
```
