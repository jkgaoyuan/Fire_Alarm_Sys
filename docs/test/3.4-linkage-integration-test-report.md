## ⚠️ 已知问题

### 1. API 路径重复显示（非阻塞性问题）

**现象**:
- OpenAPI schema 显示路径为 `/api/v1/linkage-plans/linkage-plans`
- 预期应为 `/api/v1/linkage-plans`

**原因分析**:
- FastAPI router 嵌套时 prefix 配置重叠
- `__init__.py` 中添加了 `prefix="/linkage-plans"`
- router 文件中的 endpoints 也包含了完整路径

**影响**:
- ❌ 不影响实际功能
- ❌ 不影响 HTTP 请求响应
- ⚠️ Swagger UI 显示不够简洁

**建议修复**（可选）:
```python
# app/api/v1/__init__.py
router.include_router(linkage_plans.router, tags=["Linkage Plans"])
# 移除 prefix 参数，让 router 自己处理路径
```
