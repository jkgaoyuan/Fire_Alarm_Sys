**沉淀 E2E 期间的新发现**：未发现新的生产缺陷，但修正了 4 处用例侧的错误假设，记录以免重犯：
① 详情接口不存在时返回 HTTP 200 + 响应体 `code=404`，不能用 `status_code == 404` 断言；
② 导入模板中 `设备编码*` 与 `设备名称*` 都是必需列，用这两列构造「缺列」用例实际是合法文件；
③ `扩展属性(JSON)` 单元格必须是 JSON 文本，openpyxl 无法写入 dict；
④ 回滚阈值是失败率严格大于 50%，3 行 2 失败（66%）会连带合法行一起回滚，验证「部分失败仍入库」需把失败率控制在 50% 及以下。
