## 🚀 部署步骤

### Step 1: 数据库迁移

执行 Alembic 迁移创建表结构：

```bash
cd backend
python -m alembic upgrade xxx_linkage_tables
```

**注意**: 确保 PostgreSQL 数据库正在运行且 .env 配置正确

### Step 2: 初始化权限数据

```bash
python scripts/init_data.py
```

这将创建联动预案相关的 6 个权限码及角色绑定。

### Step 3: 启动后端服务

```bash
cd backend
uvicorn app.main:app --reload
```

访问 Swagger 文档：http://localhost:8000/docs

### Step 4: 启动前端服务

```bash
cd frontend
npm run dev
```

访问前端：http://localhost:5173

## 💡 常见问题 FAQ

### Q: 为什么无法导入 JSONB？

A: SQLAlchemy 1.x/2.x 版本差异导致。请使用：
```python
from sqlalchemy.dialects.postgresql import JSONB
```

### Q: Import errors on get_db?

A: 确保从正确的模块导入：
```python
from app.core.dependencies import get_db
# NOT from app.api.dependencies import get_db
```

### Q: How to test without database?

A: Use mocks in unit tests, skip DB-dependent code paths:
```python
from unittest.mock import AsyncMock, MagicMock
db_session = MagicMock()
db_session.execute.return_value.scalar_one.return_value = 0
```

### Q: WebSocket events not triggering?

A: Check that Redis connection is available and event_stream.publish is called correctly after transaction commit.
