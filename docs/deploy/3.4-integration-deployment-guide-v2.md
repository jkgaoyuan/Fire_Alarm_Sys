## 🔍 第五阶段：端到端功能测试 (60 分钟)

### Step 1: 完整业务流程测试

#### Scenario 1: 标准预案生命周期

```
1. CREATE 创建预案 (API + UI)
   ↓
2. READ 查询列表验证
   ↓
3. UPDATE 更新预案信息
   ↓
4. TOGGLE 启用/停用切换
   ↓
5. SIMULATE 模拟触发执行
   ↓
6. VERIFY 验证日志生成
   ↓
7. DELETE 尝试删除 (应失败因为有日志)
   ↓
END 完成生命周期测试
```

**测试时长**: 约 15 分钟

---

#### Scenario 2: 自动联动引擎

```
1. CREATE 创建启用的预案 (只使用 API)
   ↓
2. SEND 发送设备上报请求 (fire alarm)
   ↓
3. WAIT 等待异步处理 (5-10 秒)
   ↓
4. QUERY 查询生成的联动日志
   ↓
5. VERIFY 验证:
   - 预案匹配正确
   - 动作被执行
   - 日志记录完整
   - 如果有失败，生成了次级故障报警
   ↓
END 验证自动触发逻辑
```

**测试时长**: 约 20 分钟

---

#### Scenario 3: 多预案同时执行

```
1. CREATE 创建 3 个不同的预案
2. ENABLE 全部启用它们
3. SEND 发送一个 fire alarm
4. VERIFY 验证:
   - 所有匹配的预案都被触发
   - 每个预案生成对应的日志条目
   - WebSocket 事件推送 (如果有 Redis)
   ↓
END 验证批量处理能力
```

**测试时长**: 约 25 分钟
